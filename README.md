## 🌐 ¿Qué es este proyecto?

Una **web completa en PHP puro** para servidores **AzerothCore** (World of Warcraft 3.3.5a). Incluye todo lo necesario para gestionar tu comunidad desde un solo lugar, sin frameworks ni dependencias externas.

### ✨ Funcionalidades

| Módulo | Descripción |
|--------|-------------|
| 📝 **Registro** | Creación de cuentas con **SRP6** (formato oficial de AzerothCore) |
| 🔐 **Login** | Inicio de sesión con sesiones PHP seguras |
| 🛒 **Tienda** | Compra de items/servicios con oro o puntos |
| 📰 **Noticias** | Publicación y gestión de noticias del servidor |
| ⚙️ **Panel Admin** | Administración de usuarios, noticias, tienda y más |

### 🎯 Filosofía

- **PHP puro**: sin Laravel, sin Symfony, sin Composer. Copias, configuras y funciona.
- **Cada módulo es independiente**: fácil de leer, modificar y ampliar.
- **Código comentado en español**: pensado para que cualquiera lo entienda.
- **Compatible con AzerothCore**: usa las bases de datos `acore_auth`, `acore_characters` y `acore_world`.
